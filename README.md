## الفلسفة

### المبادئ الأساسية

| المبدأ | التفسير |
|--------|---------|
| الحرف = مذبذب | لكل حرف تردد ذاتي ω₀ و 22 بُعداً فيزيائياً (حرارة، كثافة، حركة، صلابة...) |
| الكلمة = حزمة موجية | ناتجة عن الجداء الهندسي (Clifford product) لمتجهات حروفها — ليس متوسطاً حسابياً |
| الجملة = نظام جاذبية | كلمات تتجاذب في فضاء طوري 56 بُعداً حسب `F = G·m₁·m₂/r²` |
| المعنى = رنين طوري | حالة استقرار تنشأ من انسجام الموجات |
| التعلم = مزامنة | Hebbian synchronization في فضاء الطور — وليس backpropagation |

### ما لا يستخدمه مرنان

- ❌ شبكات عصبية من أي نوع
- ❌ خوارزميات تحسين تقليدية (SGD, Adam)
- ❌ تضمينات إحصائية (embeddings) متعلمة من البيانات
- ❌ Softmax أو توزيعات احتمالية
- ❌ Transformer attention أو positional encoding
- ❌ قوالب جامدة أو قواعد مبرمجة يدوياً

### ما يستخدمه مرنان بدلاً من ذلك

- ✅ فيزياء الحروف (22 بُعداً مهندسة يدوياً)
- ✅ جبر كليفورد الهندسي (Clifford Algebra)
- ✅ الجاذبية الدلالية (N-body gravity في 56D)
- ✅ دوائر الرنين LC بين الكلمات (مع معامل زيتا)
- ✅ مذبذبات كوراموتو (Kuramoto oscillators)
- ✅ مصفوفة الكثافة الكمومية (Quantum Density Matrix)
- ✅ حقل التدفق السببي (Causal Flow Field)
- ✅ التبريد المحاكى (Simulated Annealing)
- ✅ ذاكرة هولوغرافية معرفية (Holographic KB)
- ✅ **مؤثرات سياقية (198 كلمة: نفي، تضخيم، تباين، شرط)**

### الأسس الفيزيائية: نظرية الفتائل

مرنان مبني على **نظرية الفتائل** (Filaments Theory) — نظرية فيزيائية موحدة تنص على أن:
- كل ما في الكون ينبثق من فتيل بلانكي واحد (Planck-scale filament)
- الزمكان خصائص إحصائية ناشئة من شبكة الفتائل
- دالة زيتا لريمان هي دالة الاستجابة الترددية لشبكة دوائر LC الكمومية
- خط σ=1/2 هو خط التوازن الطاقي حيث تتساوى القوى التقلصية والتوسعية

انظر `Filaments_Theory/` للتوثيق الكامل (17 جزءاً + مختبرات حسابية).

### الطبقات المعمارية

```
┌──────────────────────────────────────────────────┐
│ 7. واجهات: CLI / REST API / Web UI               │
├──────────────────────────────────────────────────┤

├──────────────────────────────────────────────────┤
│ 5. الاستدلال: مسبب التكامل المساري               │
│    (جاذبية مزدوجة + KB-first)                    │
├──────────────────────────────────────────────────┤
│ 4. المعرفة: ذاكرة هولوغرافية                     │
│    (530 حقيقة، 12 نوع علاقة، استعلام O(1))       │
├──────────────────────────────────────────────────┤
│ 3. فيزياء الكلمة: إسقاط كليفورد الهندسي          │
│    لمتجهات الحروف في فضاء 56D                    │
├──────────────────────────────────────────────────┤
│ 2. فيزياء الحرف: 56 حرفاً                         │
│    (30 عربي + 26 إنجليزي) × 22 بُعداً            │
├──────────────────────────────────────────────────┤
│ 1. الثوابت: h=1.0, c=1.0, G=1.0                  │
└──────────────────────────────────────────────────┘
```

### من الحرف إلى الكلمة

1. **الحرف**: متجه 22D مهندس يدوياً بصفات فيزيائية (تركيز، حرارة، كثافة، حركة، صلابة، شحنة...)
2. **تعديل الحركات**: الفتحة = +0.5×طاقة الألف، الضمة = +0.5×طاقة الواو، الكسرة = +0.5×طاقة الياء
3. **الجداء الهندسي**: `w = normalize(a₁ · a₂ · a₃ · ...)` — جداء كليفورد غير تبديلي يحفظ الترتيب
4. **الفضاء الكامل 56D**: `[φ₂₂ | root₈ | extra₆ | syn₆ | sem₁₆ | prag₆]`

### من الكلمة إلى الجملة

1. **اختيار المرشحين**: الجاذبية الطورية `F = G·m₁·m₂/(4πr²)` في فضاء 56D الكامل
2. **تسجيل المرشحين**: 40+ عاملاً فيزيائياً (محاذاة الطور، السلسلة الرنينية، التغاير الترددي، DCCF، Kuramoto...)
3. **بحث شعاعي**: أعلى beam_width مرشح ينتقلون للخطوة التالية
4. **تبريد محاكى**: τ يضمحل من 2.5 → 0.15 (استكشاف → تبلور)
5. **انهيار كمومي**: بوابة إنتروبيا تنهي التوليد عند S ≤ S_crit

### عامل التسجيل الفيزيائي

كل كلمة مرشحة تُقيّم عبر المعادلة:

```
score(w) = w_align × cos(w, target)
         + w_gravity × Σ(m_ctx × m_w / (4πr²))
         + w_resonant × f_res(w, prev)
         + w_heterodyne × |f_cand ± f_ctx|
         + w_syntax × transition_score(prev, w)
         + w_kb × kb_query(w, context)
         + ... (40+ عاملاً)
```

## التدريب

مرنان لا يستخدم backpropagation ولا دالة خسارة (loss function). بدلاً من ذلك، يستخدم **المزامنة الفيزيائية**:

### التدريب الأساسي (`train.py`)

```bash
python train.py
```

ماذا يفعل:
1. يقرأ النصوص من `data/corpus.txt` و `data/dialogue_corpus.txt`
2. يحسب مصفوفات الاقتران K_sem (دلالية)، K_syn (نحوية)، K_dial (حوارية)
3. يبني حقول الطور السياقية (contextual spectra)
4. يحفظ النموذج في `model/`

المصفوفات K هي مصفوفات **تزامن فيزيائي** (synchronization)، وليست مصفوفات أوزان عصبية. تُحسب من:
- التشارك في النص (co-occurrence)
- التشابه الطوري (phase similarity) بين الكلمات
- تضمين الحقول الدلالية عبر FFT الطيفي

### التدريب التزايدي (`assimilate.py`)

```bash
python assimilate.py --data new_data.txt
```

يضيف بيانات جديدة دون إعادة تدريب كامل. يُحدّث مصفوفات K والمتجهات الطورية تزايدياً.

### التعلم الهيبياني (أثناء الاستخدام)

أثناء التوليد، يتعلم مرنان بشكل مستمر عبر:
- **PhaseReinforcement**: تعزيز طوري للكلمات المولدة (lr=0.05)
- **PhaseEvolution**: مزامنة هيبيانية للمتجهات المتجاورة (lr=0.03)
- **AssociativeMemory**: ربط الأسئلة بالإجابات في الحوار
- **InteractionTrace**: تكييف β (درجة الحرارة) حسب أنماط المستخدم

## قاعدة المعرفة

### البناء

القاعدة الهولوغرافية تخزّن الحقائق كثلاثيات `(فاعل، علاقة، مفعول)`:

```json
{"subject": "باريس", "relation": "عاصمة", "object": "فرنسا"}
{"subject": "ثلج", "relation": "يصبح_بالتسخين", "object": "ماء"}
{"subject": "سكين", "relation": "مصنوع_من", "object": "معدن"}
```

### أنواع العلاقات

`IS_A`, `LOCATED_IN`, `CAPITAL_OF`, `MADE_OF`, `PART_OF`, `USED_FOR`, `BECOMES_WHEN`, `PRODUCES`, `HAS_PROPERTY`, `CAPABLE_OF`, `SYNONYM`, `CURATED`

### إضافة حقائق

```python
from src.physics.holographic_kb import HolographicKB
from src.physics.word_physics import compute_extended_phase_vector

kb = HolographicKB(data_dir="data")
pv = lambda w: compute_extended_phase_vector(w)

# حقيقة واحدة
kb.store_fact(pv("القاهرة"), pv("مصر"), "CAPITAL_OF", subj_word="القاهرة", obj_word="مصر")

# تحميل من ملف JSON
kb.load_curated_facts("data/facts_expanded.json", vocab, pv)
```

### توسيع المفردات

أضف كلمات جديدة إلى `model/vocab_supplemental.json`:

```json
{
  "words": ["كلمة_جديدة1", "كلمة_جديدة2", "..."]
}
```

تُحمّل تلقائياً عند بدء التشغيل. أو برمجياً:

```python
vocab.load_supplemental("model/vocab_supplemental.json")
```

## أنماط التوليد

| النمط | الأمر | الوصف |
|-------|-------|-------|
| **standard** | `python cli.py "نص"` | بحث شعاعي كلاسيكي — متوازن |
| **quantum** | `--mode quantum` | تراكب كمومي مع انهيار موجة عبر EntropyGate |
| **multiverse** | `--mode multiverse` | أكوان متوازية — أبطأ لكن أغنى |
| **reason** | `--mode reason` | استدلال متعدد الخطوات — يستخدم Path Integral Reasoner + KB |
| **creative** | `--mode creative` | أخذ عينات بولتزمان بحرارة عالية — إبداعي |
| **poetic** | `--mode poetic --meter kamil` | توليد شعري مع وزن وقافية |
| **wave** | `--mode wave` | بحث مسار طيفي عبر PGN |
| **dialogue** | `--mode dialogue` | وضع حواري — يمنع الاستكمال الإحصائي |

### أمثلة

```bash
# توليد عادي
python cli.py "الصياد في الغابة"

# استدلال متعدد الخطوات
python cli.py "باريس في فرنسا. فرنسا في أوروبا. أين باريس" --mode reason

# إبداعي
python cli.py "في قديم الزمان" --mode creative --max-words 20

# شعري
python cli.py "ألا ليت شعري" --mode poetic --meter kamil --rhyme ر

# حواري
python cli.py -i --mode dialogue
```

## التخصيص والإعدادات

### ملف الإعداد (`config.yaml`)

```yaml
generation:
  beam_width: 5          # عرض الشعاع
  top_k: 500             # عدد المرشحين
  beta: 2.0              # ثابت بولتزمان

annealing:
  tau_max: 2.5           # حرارة البدء
  tau_min: 0.15          # حرارة النهاية
  tau_decay: 5.0         # ثابت الاضمحلال

kb_influence: 0.4        # وزن تأثير القاعدة المعرفية (0-1)

goal_gravity_weight: 0.3 # وزن جاذبية الهدف في الاستدلال

scoring_weights:         # أوزان عوامل التسجيل (تطبع تلقائياً)
  align: 5.0
  gravity: 5.0
  resonant_chain: 5.0
  ...
```

### ضبط الأداء

| المعامل | خفّضه إذا... | ارفعه إذا... |
|---------|-------------|-------------|
| `beam_width` | التوليد بطيء | تريد تنوعاً أكثر |
| `beta` | الإخراج عشوائي جداً | الإخراج متكرر |
| `kb_influence` | تريد إبداعاً أكثر | تريد دقة حقائق أكثر |
| `tau_max` | الجمل قصيرة جداً | الجمل متكررة |
