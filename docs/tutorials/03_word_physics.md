## المشكلة: المتوسط الحسابي يفقد الترتيب

لو أخذنا متوسط متجهات الحروف:

```python
v("علم") = mean(v("ع"), v("ل"), v("م"))
v("ملع") = mean(v("م"), v("ل"), v("ع"))
```

النتيجة: **متجهان متطابقان!** النموذج يظن أن "علم" = "ملع".

المتوسط الحسابي `mean(a,b,c) = mean(c,b,a)` — يفقد الترتيب تماماً.

## الحل: جداء كليفورد الهندسي

في جبر كليفورد، الضرب غير تبديلي: `a·b ≠ b·a`.

```
v(علم) = normalize( v(ع) · v(ل) · v(م) )  ← الترتيب: ع-ل-م
v(ملع) = normalize( v(م) · v(ل) · v(ع) )  ← الترتيب: م-ل-ع
```

النتيجة: **متجهان مختلفان تماماً** — تشابه جيب التمام بينهما ≈ 0.098 (شبه متعامدان!).

## ماذا ينتج جداء كليفورد؟

الجداء الهندسي لحرفين `a·b` يُنتج ثلاثة مكونات:

```
a·b = a·b (scalar)  +  a∧b (bivector)  +  فرق المتجهات
```

| المكون | الرتبة | الأبعاد | ماذا يمثل؟ |
|--------|--------|---------|-----------|
| Scalar | 0 | 1 | الجوهر المشترك — التداخل الداخلي |
| Vector | 1 | 22 | الأثر الفيزيائي المتبقي |
| Bivector | 2 | 231 | المستويات الدلالية الناشئة — معاني جديدة لا توجد في أي حرف منفرد |

## لماذا bivectors مهمة؟

الـ bivectors (المركبات الثنائية) هي "المعاني الناشئة" من اجتماع حرفين. لا توجد في أي حرف بمفرده.

مثال: كلمة "در" (3 أحرف) تنقل **62%** من طاقتها الإجمالية إلى فضاء الـ bivectors. هذا يثبت رياضياً أن:

> **الكلمة أكبر من مجموع حروفها.**

## طريقة الإسقاط (Projection)

للاستخدام العملي، لا نحتاج تخزين 231 بعداً. نستخدم الإسقاط:

```python
# ١. احسب الجداء الهندسي الكامل
mv = geometric_product(letter_vectors)  # scalar + vector + bivector

# ٢. اسقط bivector على vector
v_word = normalize(mv.vector + contract(mv.bivector, mv.vector))
```

هذا يعطينا متجهاً 22D غنياً بالمعلومات الهندسية، مع الحفاظ على الترتيب.

## تأثير الحركات

الحركات تُعدّل المتجهات قبل الجداء:

```python
الفتحة (َ)  → v(الحرف) += 0.5 × v(ا)
الضمة  (ُ)  → v(الحرف) += 0.5 × v(و)
الكسرة (ِ)  → v(الحرف) += 0.5 × v(ي)
الشدة  (ّ)  → v(الحرف) *= 2.0
```

النتيجة: `عَلِمَ ≠ عُلِمَ ≠ عِلْم` — كل واحدة لها متجه مختلف بسبب الحركات.

## الكتلة والطاقة

```
ω₀(كلمة) = Σ ω₀(حرف)         # مجموع ترددات الحروف
E = h · ω₀                    # طاقة الكلمة (h=1)
m = E / c²                    # كتلة دلالية (c=1)
m = min(m, 5.0)               # سقف الكتلة
```

الكلمة الأطول = كتلة أكبر = جاذبية أقوى.
