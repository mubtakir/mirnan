## نظرة عامة

التوليد في مرنان = اختيار الكلمة التالية الأكثر "تجاذباً" مع الكلمات السابقة.

لا توجد احتمالات. لا يوجد softmax. هناك **فيزياء**.

```
Prompt → (1) تحويل → (2) مرشحون → (3) تسجيل → (4) اختيار → تكرار
```

### الخطوة ٢: اختيار المرشحين بالجاذبية

لكل كلمة من الـ 167 ألف كلمة في المعجم، نحسب:

```python
ctx_center = متوسط متجهات آخر 5 كلمات  # مركز حقل السياق

# لكل كلمة i:
r² = ∥v_i∥² + ∥ctx∥² - 2·(v_i · ctx)     # مسافة إقليدية حقيقية
F_i = m_i · m_ctx / (4πr²)                 # قوة الجاذبية على سطح كرة
score_i = cos(v_i, ctx) · F_i · m_i        # درجة الرنين
```

نختار أعلى 500 كلمة (top_k=500) كمرشحين.

### الخطوة ٣: تسجيل المرشحين بـ 40+ عامل

كل مرشح يُقيّم عبر معادلة تجمع عشرات العوامل الفيزيائية:

| العامل | ماذا يقيس؟ | الوزن |
|--------|-----------|-------|
| **محاذاة الطور** | هل متجه الكلمة يشير لنفس اتجاه السياق؟ | 5.0 |
| **الجاذبية** | هل الكلمة ثقيلة وقريبة من مركز السياق؟ | 5.0 |
| **السلسلة الرنينية** | هل تردد الكلمة يتوافق مع ترددات الجملة؟ (مع معامل زيتا) | 5.0 |
| **التغاير الترددي** | هل طيف الكلمة يتداخل بناءً أو هداماً مع طيف السياق؟ | 4.0 |
| **النحو** | هل الانتقال من الكلمة السابقة صحيح نحوياً؟ | 5.0 |
| **الصرف** | هل وزن الكلمة يتوافق مع أوزان السياق؟ | 1.5 |
| **الإعراب** | هل حالة الكلمة (رفع/نصب/جر) متوافقة؟ | 1.5 |
| **القاعدة المعرفية** | هل الكلمة مرتبطة بحقيقة في الـ KB مع كلمات السياق؟ | 2.5 |

## العوامل الفيزيائية بالتفصيل

### الجاذبية (Gravity)

```
F = G · m₁ · m₂ / (4πr²)  ← شاشة هولوغرافية (نظرية الفتائل)
```

ليست مجرد cos — تستخدم المتجهات الكاملة غير المطبَّعة (56D). الحدود `∥v₁∥²` و `∥v₂∥²` مستقلة عن `-2·v₁·v₂`، مما يجعل المسافة غير قابلة للاختزال إلى cosine similarity.

### السلسلة الرنينية LC

كل كلمتين متجاورتين = دائرة رنين كهربائية:

```python
C = m₁ · m₂ · (1 + cos(θ))     # سعة دلالية
L = 1 / (1 + |sin(arccos(θ))|)  # محاثة دلالية
f = 1 / (2π√(L·C))              # تردد الرنين

# معامل زيتا — تعزيز الرنين المتوازن
ζ(cos) = 1 / (1 + (cos-0.5)²)   # ذروة عند cos=0.5
```

### التغاير الترددي (Heterodyning)

```python
# طيف 22 قناة لكل كلمة
f_cand[ch]    # تردد المرشح في القناة ch
f_ctx[ch]     # تردد السياق في القناة ch

# ترددات المجموع والفرق
f_plus[ch]  = f_cand[ch] + f_ctx[ch]   # تداخل بناء
f_minus[ch] = f_cand[ch] - f_ctx[ch]   # تداخل هدام

# درجة التغاير = مدى توافق الترددات
```
