## ١. الاستدلال متعدد الخطوات (Path Integral Reasoner)

عند استخدام `mode=reason`، لا يقوم مرنان بتوليد نص عادي — بل **يتتبع سلاسل المعرفة**:

```
Prompt: "الثلج يذوب ويصبح ماء. الماء يغلي ويصبح بخار. ماذا يصبح الثلج إذا سخن؟"

سلسلة الاستدلال:
  الثلج → (KB: يصبح_بالتسخين → ماء) → ماء
  ماء   → (KB: يصبح_بالتسخين → بخار) → بخار

الإجابة: ماء بخار
```

### كيف يعمل؟

١. **استخراج goal_concept**: مركز الكتلة الطوري للـ prompt + إثراء من الـ KB

٢. **كلمة بداية ذكية**: أول كلمة في الـ prompt تطابق حقيقة في الـ KB

٣. **جاذبية مزدوجة**: كل مرشح يُجذب باتجاهين:
   - نحو السياق المحلي (تماسك الجملة)
   - نحو goal_concept (هدف الاستدلال)

٤. **اختيار KB-first**: عندما يجد الـ reasoner حقيقة في الـ KB للكلمة الحالية، يستخدم كلماتها كمرشحات حصرية (بدلاً من البحث في الـ 167 ألف كلمة)

٥. **تتبع المسار**: كلمة → الكلمة التالية من الـ KB → ... حتى الوصول للهدف

### الاستخدام

```bash
python cli.py "باريس في فرنسا. فرنسا في أوروبا. أين باريس" --mode reason
python cli.py "السكين مصنوع من معدن. المعدن يستخرج من خام. من أين يأتي السكين" --mode reason
```

## ٢. الضبط عبر config.yaml

ملف `config.yaml` هو مركز التحكم في سلوك مرنان:

```yaml
# ─── معاملات التوليد ───
generation:
  beam_width: 5          # عدد المسارات المتوازية
  top_k: 500             # عدد المرشحين لكل خطوة
  beta: 2.0              # ثابت بولتزمان (حرارة)

# ─── تبريد محاكى ───
annealing:
  tau_max: 2.5           # حرارة البدء (استكشاف عالٍ)
  tau_min: 0.15          # حرارة النهاية (تبلور)
  tau_decay: 5.0         # سرعة التبريد

# ─── تأثير القاعدة المعرفية ───
kb_influence: 0.4        # 0.1 = تأثير ضعيف، 0.7 = تأثير قوي

# ─── الاستدلال ───
goal_gravity_weight: 0.3 # وزن الجاذبية نحو الهدف
reasoning:
  beam_width: 10
  max_depth: 8
  min_depth: 2
  convergence_threshold: 0.75

# ─── أوزان التسجيل (تُطبَّع تلقائياً) ───
scoring_weights:
  align: 5.0             # محاذاة الطور
  gravity: 5.0           # الجاذبية
  resonant_chain: 5.0    # السلسلة الرنينية
  syntax: 5.0            # النحو
  kb_knowledge: 2.5      # القاعدة المعرفية
```

### دليل الضبط السريع

| المشكلة | الحل |
|---------|------|
| الجمل قصيرة جداً | ارفع `beam_width` إلى 8، و `tau_max` إلى 3.0 |
| الجمل مكررة | ارفع `tau_max` إلى 3.0 |
| الجمل غير متماسكة | اخفض `tau_max` إلى 1.5 |
| لا تظهر حقائق الـ KB | ارفع `kb_influence` إلى 0.7 |
| الـ KB يسيطر كثيراً | اخفض `kb_influence` إلى 0.1 |
| الاستدلال يتوقف مبكراً | اخفض `convergence_threshold` إلى 0.65 |
| الاستدلال لا يتقارب | ارفع `max_depth` إلى 12 |

## ٣. الأنماط المتقدمة

### الوضع الإبداعي (Creative Mode)

يستخدم أخذ عينات بولتزمان `P(w) ∝ exp(score / τ)` بدلاً من البحث الشعاعي الحتمي. معاملات:

```yaml
creative:
  tau: 1.2            # حرارة عالية = تنوع أكبر
  tunnel_prob: 0.05   # احتمال القفز الكمومي (استعارة)
  perturbation: 0.15  # شدة الاضطراب الطوري
```

### الوضع الكمومي (Quantum Mode)

يحتفظ بـ 15 مساراً في حالة تراكب. ينهار المسار عندما تنخفض الإنتروبيا:

```python
if S ≤ S_crit:
    collapse()  # اختر المسار الأعلى تماسكاً
```

### الوضع الشعري (Poetic Mode)

يدعم 16 بحراً عربياً (كامل، طويل، بسيط، وافر...) مع تفعيلة فيزيائية وقافية.

```bash
python cli.py "ألا ليت شعري" --mode poetic --meter kamil --rhyme ر
```

## ٥. المؤثرات السياقية (Contextual Operators) — V9

أحدث إضافة لمرنان: **كلمات تعدّل العلاقة الفيزيائية بين المتضادات**.

### المشكلة

"شمس" و"ظلام" متعاكسان فيزيائياً في الفضاء الهندسي (Bivectors متعاكسة). في الجملة العادية، لا يمكنهما الظهور معاً. لكن:

> "عند **غياب** الشمس **يطغى** الظلام"

"غياب" و"يطغى" **تكسران التعارض** وتخلقان جسراً سببياً.

### كيف يعمل؟

```python
from src.physics.operators import ContextualOperators

co = ContextualOperators()

# كشف المؤثرات في السياق
chain = co.detect_chain(["عند", "غياب", "الشمس", "يطغى", "الظلام"])
# → [(1, "غياب", "negation", -0.8), (3, "يطغى", "amplify", 1.5)]

# المؤثرات تُضاف تلقائياً في _score()
# الكلمات القريبة من مؤثر تحصل على تعزيز
```

### أنواع المؤثرات (198 كلمة في JSON خارجي)

| النوع | العدد | أمثلة | التأثير |
|-------|-------|-------|---------|
| **negation** | 64 | غياب، عدم، ليس، لن، لم، زوال | يعكس الأبعاد المهيمنة للمتجه |
| **amplify** | 66 | يطغى، يشتد، يعم، يسود، يفيض | يضخم المتجه ×1.5 |
| **contrast** | 37 | رغم، لكن، إلا، بينما، بل | يضعف التعارض بنسبة 50% |
| **conditional** | 31 | إذا، لو، إن، لولا، كلما | ينشئ مساراً سببياً |

### إضافة مؤثرات جديدة

افتح الملف `src/physics/operators/contextual_operators.json` وأضف كلمتك في الفئة المناسبة:

```json
{
  "negation": {
    "strength": -0.8,
    "words": ["غياب", "اختفاء", "كلمتك_الجديدة", ...]
  }
}
```

لا حاجة للمس الكود. المؤثرات تُحمّل تلقائياً عند بدء التشغيل.

### مثال تطبيقي

```bash
python cli.py "عند غياب الشمس يطغى الظلام" --mode standard
```

مرنان سيكتشف "غياب" (negation) و"يطغى" (amplify)، فيفهم أن الجملة منطقية رغم تعارض شمس-ظلام فيزيائياً.
